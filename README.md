# Juego Educativo - Tesis

Un juego educativo interactivo desarrollado como proyecto de tesis universitaria. Este proyecto combina gamificación con aprendizaje para crear una experiencia educativa atractiva y efectiva.

## Descripción

Este repositorio contiene el código fuente de un juego educativo diseñado para estudiantes entre 8 y 16 años que ayuda a los estudiantes a fomentar la creatividad de forma interactiva y divertida.

## Características

- Interfaz interactiva y amigable
- Contenido educativo estructurado
- Sistema de puntuación y recompensas
- Seguimiento del progreso del usuario
- Diseño responsivo
- Compatible con navegadores modernos

## Tecnologías

- Frontend: JavaScript, HTML5, CSS3
- Backend: NodeJS + Express
- Base de Datos: MySQL
